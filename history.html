History of HTTP

1991 - HTTP/0.9 released
The first version of HTTP was really simple and straightforward. The requests consisted of a single line and started with the only single method, GET, followed by the path to the resource. The response is a simple one as well, consisting of the raw data of the resource requested.

1996 - HTTP/1.0 released

1999 - HTTP/1.1 released

2015 - HTTP/2 released

2022 - HTTP/3 released
