Concepts of HTTP

HTTP is a client-server protocol that is used to fetch resources like HTML documents, images, videos, and scripts and is considered the foundation of the world wide web.

HTTP operates under a client-server architecture, where the client (usually a web browser) sends a request to the server, and the server responds with the requested resource.

HTTP was founded by Tim Berners-Lee who wrote a proposal to build a hypertext system over the internet. It was initially called MESH, but was later renamed to the World Wide Web when it was implemented in 1990

In HTTP, there are three-digit numeric codes that are returned by the server to indicate the status of the request. For example, 2xx indicated success (200 OK), 3xx indicates redirection (301 Moved Permanently), 4xx indicates client errors (404 Not Found), and 5xx indicates server errors (500 Internal Server Error).

Some of the most commonly used methods in HTTP include GET (retrieve data), POST (send/create data), PUT (update/replace data), and DELETE (remove data).

HTTPS is an extension of HTTP that encrypts traffic using TLS/SSL to protect data privacy and integrity between the client and server. That's why HTTPS is widely used for secure communication on the web, especially for sensitive transactions like online banking and e-commerce.
