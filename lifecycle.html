Life cycle of HTTP

1. The client opens a TCP connection (or QUIC association) to the server to initiate communication.

2. The client then sends an HTTP request to the server, which includes a method (like GET or POST), the requested resource's URL, and any necessary headers.

3. The server parses the request line and headers, processes the resource, and crafts a response message. The structure of the response includes a status line, headers, and the requested resource's body.

4. After those proecesses finish, the server sends the response back to the client over the established connection.
